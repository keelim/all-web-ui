# all-web-ui Component Reference Board Prompt

Create a desktop web component reference board for the `all-web-ui` shared
React UI package.

**PLATFORM:** Web, desktop-first.

**PAGE STRUCTURE:**

1. **Compact Header:** Show the package name, a short system label, and one
   small status area for design-system sync state.
2. **Actions:** Show primary, secondary, ghost, and danger actions in compact
   rows with disabled examples.
3. **Form Controls:** Show inputs, textarea, select, checkbox, switch, radio
   group, slider, and labels in dense admin-friendly layouts.
4. **Feedback:** Show alerts, toast-style messages, loading panel with steps,
   progress, skeleton, and empty state.
5. **Data Display:** Show card, panel, metric cards, badges, avatar, table,
   tabs, accordion, breadcrumb, tooltip, hover card, popover, sheet, dialog, and
   alert-dialog previews.
6. **Finance Examples:** Include dense metrics, market up/down/flat status
   chips, compact tabular data, and a loading state.
7. **Admin Examples:** Include a monochrome console section, settings row,
   confirmation dialog preview, and status alert.

**CONSTRAINTS:**

- Use generated copy, names, numbers, and dates as reference placeholders only.
- Focus on layout, content, information density, hierarchy, and component
  relationships.
- Do not include colors, fonts, hex values, HSL values, radius values, token
  names, or theme instructions. The active Stitch design system supplies those.
- Do not create app routes, navigation flows, product workflows, dashboards, or
  business logic.
- Keep the board suitable for translating into reusable package primitives,
  tokens, or documentation only.
