# Package integration traps

Invalid hook calls after installation can come from duplicate or incompatible React peers. Check React/React DOM 19 alignment in the consuming lockfile before changing component code.

A local workspace build may pass while an independent consumer cannot install. Verify registry mapping and package-read authentication separately; do not replace a published version with an undeclared sibling path.

An exported component can appear correct in source while its published CSS or declarations are missing. Build verification checks the emitted package, including relative ESM specifiers and dependency classifications. Inspect the packed artifact before attributing a consumer failure to application code.

A design upload can succeed without updating the remote design text. Retrieve `get_project.designTheme.designMd` and compare actual content before marking local synchronization metadata complete.
